Direct After Effects from a conversation.

An MCP server that lets Claude build and edit real After Effects projects: camera rigs, seamless cuts, text reveals and UI animation, in a style you define. Claude renders frames to check its own work, and you refine by hand.

How a request becomes a comp

Everything runs on your machine. Claude never touches your files directly; it sends small scripts that After Effects runs.

  1. You describe it

    “Build a 60-second explainer synced to this voice-over, blue palette, five scenes.”

  2. Claude plans and writes a job

    Scenes, shots and the move that carries each cut, sent as ExtendScript with the style library attached.

  3. After Effects runs it

    Through AppleScript on macOS, or the Claude Bridge panel on Windows. Each job is one undo step.

  4. Claude checks the result

    It renders frames after each cut and mid-shot, then fixes framing, timing and overlaps before you look.

What it builds

The library behind the tools knows motion-design structure, so a request turns into a project you can open and keep editing.

A camera that's always alive
A control null with slow drift, a controller that carries every move and a 50 mm camera per shot. Glides, punches, cranes and trucks.
Seamless cuts
Split-move cuts between shots and whip joins between scenes, with the same direction and ease on both sides.
Text that reads
Word-by-word blur-rise, bounce, highlight and character reveals, with accent-coloured key words.
UI built from shapes
Cards, pills, charts, checklists, connectors, chat bubbles and slot-machine number rolls, all editable layers.
Images with presence
Blur-pop, logo tumble and video pop entrances, soft shadows and an idle float.
A way out of every box
Raw ExtendScript with the library loaded, layer inspection, frame renders and undo.

Set it up in five minutes

  1. Install Node.js 18 or newer and clone the repository.
  2. In After Effects, turn on Allow Scripts to Write Files and Access Network (Settings → Scripting & Expressions).
  3. Add the server to Claude Code or Claude Desktop, open a project and ask Claude to check the connection.

Full setup guide

# get the code
git clone https://github.com/thoshiranchanilka/After-Effects-Claude-MCP.git
cd After-Effects-Claude-MCP
npm install && npm test

# connect it to Claude Code
claude mcp add after-effects -- node "$(pwd)/dist/server.mjs"

Build in your style, not a template

The server ships with a clean starter style. Run the exporter on a few of your finished projects and Claude turns them into a style profile: move timings, eases, distances, type, reveals and palettes.

Keep that profile anywhere and point the server at it. Your look stays yours.

Teach it your style

# use your own profile
claude mcp add after-effects \
  -e AE_STYLE_PROFILE="/path/to/my-style/profile.json" \
  -- node "/path/to/dist/server.mjs"

Fifteen tools

Claude picks the right one for each step. You can also ask for any of them by name.

ToolWhat it does
ae_statusChecks that After Effects is reachable and lists the comps.
get_style_guideReturns the active style guide and profile.
build_storyboardBuilds a whole video from a storyboard: scenes, shots, cuts, text, images and the Main comp.
create_scene, add_shotStart a scene on the camera rig and add shots to it.
move_camera, split_cutKey a camera move, or join two shots with one shared move.
add_text, add_image, animate_layerAdd content with reveals, entrances and exits.
place_scene, inspect_comp, render_frameAssemble scenes in Main, read layers and keys, render a frame to look at.
run_extendscript, undoRun any ExtendScript with the library loaded; undo the last steps.
