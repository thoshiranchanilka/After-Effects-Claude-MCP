Claude Desktop

No terminal, no Node, no config file

Using the Claude Desktop app? Install it like any other app. Claude Desktop brings everything the server needs.

  1. Download the extension file.
  2. Double-click it, or drag it into Claude Desktop → Settings → Extensions, then press Install.
  3. In After Effects, tick Settings → Scripting & Expressions → Allow Scripts to Write Files and Access Network.
  4. Open a project and ask Claude to check the connection.

Good to know

What you need

Adobe After Effects on the same computer, and the Claude Desktop app. That is all: no Homebrew, no Node.js, no editing JSON.

The extension ships with a clean starter style (Inter font). On Windows you may also need the small Claude Bridge panel; the setup guide shows how.

Quick start

Running in five minutes

Node 18+, After Effects with "Allow Scripts to Write Files and Access Network" turned on, and one command.

# get the code
git clone https://github.com/thoshiranchanilka/After-Effects-Claude-MCP.git
cd After-Effects-Claude-MCP && npm install && npm test

# connect it to Claude Code
claude mcp add after-effects -- node "$(pwd)/dist/server.mjs"

Feeling lazy? Paste the repo link into Claude Code and ask it to install it. It clones, tests and connects the server for you.

Your style

Build in your look, not a template

It ships with a clean starter style. Export your own projects into a style profile, keep it private, and point the server at it.

claude mcp add after-effects \
  -e AE_STYLE_PROFILE="/path/to/my-style/profile.json" \
  -- node "/path/to/dist/server.mjs"
